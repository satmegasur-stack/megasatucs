Cifrado de datos

Todos los datos se guardan cifrados en Firebase (AES-256-GCM) con la clave de cifrado; solo quien la conoce puede leerlos. Si se pierde la clave, los datos no se pueden recuperar.

Todos los datos se volverán a cifrar con la clave nueva. Asegúrate de que nadie más esté usando la aplicación: las demás sesiones abiertas se cerrarán y tendrán que iniciar sesión con la clave nueva. Si pierdes la clave nueva, los datos no se podrán recuperar.

Copia de seguridad de todos los datos

Exporta todos los datos de la aplicación (recogidas, transporte, incidencias, seguimiento y contabilidad RMA, usuarios y delegaciones) a un archivo Excel, o restáuralos a partir de un archivo exportado anteriormente. Ojo: el archivo Excel exportado NO está cifrado, guárdalo en un lugar seguro.
